Crie uma landing page de validação de demanda para um futuro SaaS chamado **ResíduoSafe**.

IMPORTANTE: esta landing page NÃO deve parecer que o produto já está totalmente disponível.

O objetivo principal é **validar interesse real no problema e captar potenciais clientes antes de desenvolver o SaaS**.

O visitante deve entender rapidamente:

1. Qual problema estamos resolvendo.
2. Para quem é o produto.
3. Como pretendemos resolver.
4. Por que isso pode facilitar a rotina da clínica.
5. Que o produto está em fase de validação/desenvolvimento.
6. Que ele pode entrar na lista de interessados.

O objetivo principal da página é fazer o visitante preencher o formulário.

# POSICIONAMENTO

O ResíduoSafe será uma plataforma para ajudar clínicas, consultórios, dentistas, veterinários e outros estabelecimentos de saúde a organizar e acompanhar a documentação relacionada à gestão de resíduos.

A plataforma pretende centralizar:

- Coletas
- MTRs
- Certificados de destinação
- Documentos da empresa coletora
- Licenças
- Vencimentos
- Alertas
- Organização documental
- Auditoria inteligente
- Preparação da documentação para fiscalização

IMPORTANTE:

Não afirmar que o sistema garante conformidade legal.

Não afirmar que o sistema evita multas.

Não fazer promessas jurídicas.

Utilizar linguagem como:

"ajudar a organizar"
"centralizar"
"acompanhar"
"identificar possíveis pendências"
"facilitar a organização documental"
